# QA Practice – Manual Testing Assignment

This repository contains a practical **Manual QA test assignment** completed using the QA Practice website.

The project demonstrates my ability to work with test documentation, organize test coverage, document defects, and summarize testing results.

## Project Scope

The assignment includes:

* test suite overview;
* checklists;
* bug reports;
* test report;
* an example of test case structure and formatting.
